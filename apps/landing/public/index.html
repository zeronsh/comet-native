Runs what you already use

Zeron is not a new harness. It drives Claude Code, Codex, Cursor, Grok, Hermes and Pi — the same sessions and tools you use each day, in one fast native window on every device.

Star on GitHub ↗

Three screens, one session

Sessions live on your machines, every device you own can pilot them. Start Claude Code at your desk, watch it from your phone, approve the diff from the couch. Nothing to hand off, nothing to re-open.
